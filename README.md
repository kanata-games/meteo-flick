# METEO FLICK / メテオ・フリック

ブラウザ向け落下パズル＋打ち上げアクションゲーム。  
同色メテオを揃えて点火し、上に積まれた塊ごと宇宙へ打ち上げる。空中再点火・押し上げ・惑星固有物理・特殊メテオを軸に、CLASSIC / PLANET / 将来のROGUEへ拡張する。

- 公開版: https://kanata-games.github.io/meteo-flick/
- テスト版: https://kanata-games.github.io/meteo-flick/test-menu.html
- Repository: `kanata-games/meteo-flick`
- Main branch: `main`

---

## 1. ゲームの核

盤面は7列×12段。

### 基本ループ

- ブロックを縦方向にスライドして入れ替える
- 同色を縦または横に3つ揃える
- 点火した位置から上の塊ごと打ち上がる
- 画面上端まで射出できれば消去＋スコア
- 空中でさらに3つ揃えると再点火・コンボ
- 落下中の塊を下から打ち上げた塊で押し上げてもコンボ
- 燃えカスも再利用可能
- 盤面上端からあふれるとゲームオーバー

### 早送り

右上の下向きボタンを押している間、落下・出現を早める。
早送り中は時間に応じてボーナス点が入る。

## 2. モード

### CLASSIC

従来ルールのエンドレススコアアタック。

- 30秒ごとにレベルアップ
- 時間経過で落下速度・出現速度が上昇
- Lv.4以降は6色目が追加
- ローカル自己ベストあり
- オンラインTOP10ランキング対応

CLASSICのランキング送信はCLASSICのみ。PLANET / PLANET ENDLESSのスコアを送らないこと。

### PLANET

惑星ごとに物理・特殊メテオ・環境ギミック・ミッションが変わるステージモード。

役割:
- 各特殊ルールを単体で学ぶ
- 将来ROGUEに入る前の「教材兼攻略モード」
- 世界観・観測ログ・図鑑解放の土台

### ROGUE（将来）

未実装。

方向性:
- PLANETで覚えた物理・特殊メテオ・環境ギミックをランダム混成
- ステージクリアごとに3択レリック等を選ぶ
- 毎回違うビルドを作る
- ROGUE専用の壊れレリック・特殊物も追加可能
- 危険物がビルド次第で強みに変わる設計を重視

例:
- 雷消去スコア増加
- アンカーが多いほど打ち上げ倍率増加
- 嵐中スコア倍率
- プリズム点火強化
- ボム爆発範囲強化
- 暴発時間短縮の代わりに爆発威力増加

## 3. PLANET進行

一本道ではなく、途中から行き先を選べる。

### 現在の解放ルール

1. 最初は **ルナ・ヴェイル** のみ
2. ルナCLEAR後、以下3惑星を同時解放
   - グラヴィタス
   - テンペスト9
   - プリズマリア
3. 上記3惑星のうち **2つCLEAR** すると **ボルカ・ゼロ** 解放

狙い:
- 無理に固定順で遊ばせない
- 「星間航路から行き先を選ぶ」感を出す
- STORYを攻略順に依存させない

## 4. 現在の5惑星

### 1. ルナ・ヴェイル / LUNA

テーマ: 低重力

- 打ち上げた塊が長く滞空
- 落下もゆっくり
- 空中再点火・押し上げを狙いやすい
- PLANETでは5色固定

MISSION:
- メテオを60個射出

進行ポップアップ:
- 20個: 軌道安定化 1/3
- 40個: 軌道安定化 2/3 + あと20個

役割:
- PLANET物理差の入門

### 2. グラヴィタス / GRAV

テーマ: 高重力＋アンカー

- 強重力
- 打ち上げた塊が失速しやすい
- アンカー・メテオが出現

MISSION:
- アンカーを8個射出

アンカー:
- 通常色を持つ
- 3つ揃いに普通に参加できる
- 塊に混ざると実質重量が増え、打ち上げにくくなる
- 宇宙へ射出するとミッション加算

役割:
- 重い特殊メテオの扱いを覚える

### 3. テンペスト9 / STORM

テーマ: 9秒間のメテオ嵐

- 開始後しばらくして警報
- 3秒前警告
- 9秒間、約0.6秒ごとに1〜2個程度のメテオが波状降下
- 嵐中は落下速度も少し上昇
- 嵐終了後は立て直し時間
- ENDLESSではレベル上昇に応じて嵐中の降下間隔も短縮

MISSION:
- 75秒生存

#### ⚡ 雷メテオ

テンペスト9の嵐中のみ低確率で出現。

- 通常色を持つ
- 雷メテオを含む3つ揃えが成立すると通常点火はキャンセル
- 点火位置へ落雷
- 画面上端から点火地点まで縦一列を消去
- 落雷消去は低得点
- 通常の打ち上げ成功の方が明確に高得点

意図:
- 非常用の盤面整理
- スコア最適解ではなく、生存・戦術用
- 将来ROGUEで雷ビルドへ変化可能

### 4. プリズマリア / PRISM

テーマ: 万能色メテオ

MISSION:
- プリズム点火を12回成功

#### 🌈 プリズム・メテオ

- 色合わせのワイルドカード
- `赤 + 🌈 + 赤` → 成立
- `赤 + 🌈 + 青` → 不成立
- `赤 + 🌈 + 🌈` → 成立
- `🌈 + 🌈 + 🌈` → 不成立
- 空中再点火でもミッション加算

役割:
- 「特殊メテオを積極的に利用してコンボを作る」入門

### 5. ボルカ・ゼロ / VOLCA

テーマ: 時限ボム

MISSION:
- ボムを10個安全起爆

#### 💣 ボム・メテオ

- 通常色を持つ
- 初回着地時に8秒の導火線開始
- 残り秒数をブロック上へ表示
- 3つ揃いに含めれば安全起爆
- 安全起爆すると周囲を局所爆破し、ミッション加算
- 放置すると自動暴発
- 暴発はミッション加算なし
- 一度導火線が開始すると、打ち上げ中もカウント継続
- 宇宙まで逃がせれば消える

役割:
- リスク管理
- 「便利だが放置すると邪魔」という特殊物

## 5. PLANET ENDLESS

各惑星を一度クリアすると、星間航路の惑星選択画面で

保存キー:

- `meteoflick_endless_gravitas`
- `meteoflick_endless_tempest`

## 9. 主要物理値・既存コードの考え方

基準値はCLASSIC。

代表的な定数:

```js
const COLS = 7;
const ROWS = 12;
const LEVEL_TIME = 30;
const ASH_T = 1.1;
const CHAIN_T = 1.5;
```

主な物理パラメータ:
- `P.G` 重力
- `P.TH` 推力
- `P.TERM` 終端落下速度
- `P.GF / P.TF` 打ち上げ後の落下側物理
- `P.PV` 押し上げ時の速度継承
- `P.RF / P.RI` 再点火
- `P.SNAP` 着地直前のマッチ猶予
- `P.FX / P.FSX / P.FB2` 早送り関連

落下メテオ:
```js
const T = {
  FS0: 1.6,
  FSL: 0.25,
  FSMAX: 5,
  SI0: 1.7,
  SIL: 0.1,
  SIMIN: 0.45
};
```

惑星開始時にCLASSIC基準へ戻したあと、その惑星の差分を適用する。

この設計を維持すること。  
CLASSICを惑星調整の影響で壊さない。

## 13. 開発方針

### 相談 → 小実装 → テスト版 → 本番

この順番を守る。

### まず面白さ、そのあと作り込み

惑星を追加するときは、
1. その惑星だけの一言で説明できる個性
2. 実際に触って違いが分かる
3. 将来ROGUEへ持ち込んだ時に別の価値を持てる
を重視する。

### 特殊物は万能な正解にしない

例:
- 雷: 盤面整理は強いが打ち上げより低得点
- アンカー: 邪魔だが将来ビルド次第で強みにできる
- ボム: 安全起爆は便利だが放置で暴発
- プリズム: コンボを作りやすいがプリズムだけでは点火不可
